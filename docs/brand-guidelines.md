# FRAU WONG HAUS — Brand Guidelines v2.0

> **Sound is your tool. Presence is the ritual.**
> Берлинский рейв-ретрит, который выглядит как наклейка на флаере, бенто-коробка из кислотного пластика и экран раскладушки 2004 года одновременно.

v2 — тот же чёрный и тот же зелёный, но **громче**: бенто-сетки, Y2K-стикеры, жирный шрифт с тенью-экструзией, кислотная палитра и коллажи из фото.

### 2.2 Пропорции

```
Void Black      ██████████████████████████████  ~55%
Accent tiles    ████████████████                ~30%  (lime / pink / blue / violet — максимум 3 в одном кадре)
Cream / White   ██████                          ~10%
Signal Green    ██                              ~5%   (только самое важное)
```

**Правило трёх:** в одной композиции не больше трёх акцентных цветов + чёрный + крем. Signal Green не считается — он всегда есть.

### 2.3 Контраст (WCAG)

| Текст → Фон | Ratio | Оценка |
|---|---|---|
| Black на Signal Green | 14.7 : 1 | AAA |
| Black на Acid Lime | 16.9 : 1 | AAA |
| Black на Cream | 18.6 : 1 | AAA |
| Black на Hot Pink | 5.7 : 1 | AA |
| Black на Blaze Orange | 6.0 : 1 | AA |
| White на Electric Blue | 8.4 : 1 | AAA |
| White на Ultra Violet | 6.0 : 1 | AA |
| Acid Lime на Electric Blue | 7.1 : 1 | AAA |
| Signal Green на Electric Blue | 6.1 : 1 | AA |

**Запрещено для текста:** белый на зелёном/лайме (1.2–1.4), чёрный на синем (2.4), розовый на синем (2.4).
Исключение — дисплейный стикер-шрифт **с чёрной экструзией** (см. 3.3): обводка/тень несёт контраст, сам цвет — декор.

### 3.3 Приёмы

- **Экструзия (Sticker Shadow).** Жёсткая чёрная тень без блюра, смещение по диагонали + обводка. Главный приём v2.
  ```css
  .sticker-type {
    font-family: var(--font-sticker);
    -webkit-text-stroke: 3px #000;
    paint-order: stroke fill;
    text-shadow: 4px 4px 0 #000, 6px 6px 0 #000, 8px 8px 0 #000;
    transform: rotate(-6deg);
  }
  ```
- **Контур + заливка.** Повтор слова: первое — только контур, второе — сплошное. `OWERS FLOWERS` → `RITUAL RITUAL`.
- **Наклон −6°…−10°.** Только для стикер-шрифта и бейджей. Bebas Neue — всегда ровно.
- **Многоцветное слово.** Буквы одного слова в разных акцентах (`F` pink, `W` blue, `H` lime) — только для логотипа-стикера и паттерна.
- **Inline-иконки.** Эмодзи-подобная 3D-иконка вместо буквы или между словами: `SOUND ✿ IS ⟶ YOUR TOOL`.
- **Растяжка/перспектива.** Слоган на волне или в перспективе («BRINGING YOUR BRAND TO THE SOCIAL DANCEFLOOR») — одна такая плашка на страницу.

## 4. Логотип

### 4.1 Варианты

| Вариант | Описание | Где |
|---|---|---|
| **Primary Wordmark** | `FRAU WONG HAUS` — Bebas Neue, Signal Green или White, в одну строку | Навигация, футер, документы |
| **Stacked** | `FRAU / WONG / HAUS` в три строки, выключка влево | Hero, постеры, сторис |
| **Sticker** | Rubik Mono One, наклон −8°, каждое слово своим цветом (Lime / Pink / Blue), чёрная экструзия | Мерч, соцсети, обложки, стикеры |
| **Monogram** | `FWH` в стикер-стиле | Аватар, фавикон, паттерн, браслеты |

### 4.2 Монограмм-паттерн

Повторяем `FWH` стикер-стилем на Electric Blue, с наклоном −20°, цвета чередуются Lime → Pink → Blue-violet (`#4d5bff`). Плотность — как обои, обрезка по краям обязательна. Используем на подложках, упаковке, мерче.

### 4.3 Правила

- Охранное поле = высота буквы `F`.
- Минимум: wordmark 96px / 25mm, монограмма 24px / 8mm.
- Sticker-логотип — только на однотонном фоне (Blue, Pink, Black). Никогда — на фото без плашки.
- ✗ Не растягивать, не менять наклон на положительный, не убирать экструзию у стикер-версии, не делать градиенты внутри букв, не ставить Signal Green на Acid Lime.

## 5. Сетка — Bento

Главная композиционная система v2. Всё, что есть у бренда, раскладывается по ячейкам.

### 5.1 Параметры

| Токен | Значение |
|---|---|
| Колонки | 12 (desktop) / 6 (tablet) / 2 (mobile) |
| Зазор | 16px desktop, 12px mobile |
| Радиус модуля | 24px (крупные), 16px (мелкие), 999px (пилюли-теги) |
| Внутренний отступ | 24–40px |
| Обводка тёмного модуля | 2px Acid Lime или Signal Green |
| Внешние поля страницы | 16px mobile / 48–80px desktop |

### 5.2 Типы модулей

| Модуль | Фон | Содержимое |
|---|---|---|
| **Manifest** | Ultra Violet / Hot Pink, вертикальный | Bebas Neue на весь модуль, стрелка внизу: `(TO DANCE) (TO BE)` |
| **Photo** | Фото full-bleed | Портрет / деталь, поверх 1–2 стикера |
| **Statement** | Electric Blue / Acid Lime | Один огромный слоган, 3D-объект вылезает за край |
| **Icon** | Cream или Pink, квадрат | Одна иконка или 3D-смайл по центру |
| **Ticker** | Acid Lime, полоса во всю ширину | Пиксельный/моно-текст, бегущая строка |
| **Definition** | Black + 2px обводка Lime | Тег-пилюля `noun` + mono-текст определения |
| **Data** | Black / Cream | Цифры Bebas Neue: `5 DAYS · 3 STAGES · 200 PEOPLE` |
| **Meta-strip** | Любой | Тег-пилюли `@frauwonghaus` / `BERLIN` / `12'26` в углах модуля |

### 5.3 Правила сборки

1. Сетка жёсткая, **объекты — нет**: 3D-элементы, стикеры и курсоры *перекрывают* границы модулей (утка, телефон, кукла в референсах). Минимум один «вылет» на композицию.
2. Рядом не ставим два модуля одного цвета.
3. В каждом кластере: 1 фото + 1 крупный текст + 1–2 мелких иконки/меты.
4. Мелкие mono-подписи в углах модулей (`001`, `7'26`, `frauwonghaus`) — «технический» слой, без него сетка выглядит пусто.

## 7. Фотография

- **Сюжеты:** крупные планы лица, губ, рук, глаз — с декором (стразы, цветы, кольца-леденцы, грилзы, блёстки). Люди в движении на танцполе. Детали: винил, провода, браслеты.
- **Свет:** вспышка в лоб, насыщенно, «журнальный» Y2K. Либо мягкий холодный дневной для портретов.
- **Цвет:** насыщенность +15–20%, фон фото по возможности однотонный и в палитре бренда (жёлтый, голубой, серый).
- **Обработка:** плёночное зерно (как `.noise` на сайте), лёгкий хроматизм, без бьюти-ретуши.
- **Поверх фото:** максимум 2 стикера + 1 тег. Лицо не перекрываем больше чем на 15%.
- ✗ Стоковые «толпа с руками вверх», дым-лазеры-силуэты, пастель, ч/б-грусть.

## 8. Голос и тон

### 8.1 Характер

| Мы | Мы не |
|---|---|
| **Ритуальные** — говорим про присутствие, звук, тело | Эзотерические: «вибрации вселенной», «чакры» |
| **Дерзкие** — коротко, ударно, с юмором | Грубые ради грубости, токсичные |
| **Тёплые** — «мы», «вместе», приглашение | Холодно-элитарные «not for everyone» |
| **Загадочные** — недосказанность, локация секретна | Непонятные: шифр без ключа |

### 8.2 Правила письма

- Заголовки — 2–5 слов, утверждение, точка. `Sound is your tool.`
- Двуязычность: EN — основной, DE — вкрапления (`Willkommen. Tanz.`), RU — для русскоязычных каналов.
- Номера секций в mono: `001 Philosophy`, `002 Program`.
- CTA — глагол + ритуал: **Join the Ritual**, **Get Early Access**, **Claim Your Spot**, **Find the Door**.
- Микрокопи с подмигиванием: `No spam. No noise. Just signal.`

### 8.3 Лексикон

**Да:** ritual, signal, presence, sound, gather, dawn, underground, between beats, frequency, door.
**Нет:** epic, insane party, VIP experience, wellness journey, synergy, «не пропусти!!!».

### 8.4 Слоганы

- Sound is your tool. Presence is the ritual.
- More ✶ or ☺ less.
- Find the door. We'll find the beat.
- Five days. Three stages. One consciousness.
- Between beats, we meet.

## 9. Motion

- **Easing:** `cubic-bezier(0.16, 1, 0.3, 1)` (out), `cubic-bezier(0.87, 0, 0.13, 1)` (in-out).
- **Появление модулей:** снизу вверх 24px + fade, stagger 60ms по сетке.
- **Стикеры:** «шлёп» — scale 1.2 → 0.95 → 1 с поворотом ±4°, 400ms.
- **Hover модуля:** подъём −4px + сдвиг тени `6px 6px 0 #000` → `10px 10px 0 #000`.
- **Бегущая строка:** 40s linear, пауза на hover.
- **3D-объекты:** медленный float ±8px, 6s, бесконечно.
- Уважать `prefers-reduced-motion`: оставить только fade.
