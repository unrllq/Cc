# NEON MILE — Cyber Rider over London

Аркадный полёт на кибер-байке над лондонским Сити. Камера — за спиной, как в AAA:
пружинный «спринг-арм», коллизия камеры со зданиями, FOV-кик и тряска на форсаже.
Режим — **RING RUN**: 12 неоновых колец по трассе через Сити на время.


## Запуск

ES-модули не работают через `file://`, поэтому нужен любой локальный сервер:

```bash
cd game
python3 -m http.server 8123
# открыть http://localhost:8123/
```

Всё остальное — офлайн: three.js лежит в `vendor/`, текстуры и звук генерируются в рантайме.

## Управление

| Действие | Клавиши |
|---|---|
| Тяга | `W` / `S` |
| Тангаж, рыскание | мышь (или стрелки) |
| Крен / вираж | `A` / `D` |
| Форсаж | `Shift` |
| Вверх / вниз | `Space` / `Ctrl` |
| Камера: chase → close → cockpit | `C` |
| Респавн на последнем чек-пойнте | `R` |
| Пауза и настройки | `Esc` |

Поддерживаются геймпад (левый стик — нос, правый — крен, RT — тяга, A — форсаж)
и тач (джойстик слева, кнопки справа).

## Подключить модели со Sketchfab

Sketchfab-эмбед — это iframe: модель внутри него нельзя сделать игровым объектом.
Поэтому игра рисует собственный процедурный байк и город, но умеет подхватывать
реальные модели, если положить их в `assets/`:

| Файл | Что заменяет |
|---|---|
| `assets/bike.glb` | процедурный байк с райдером |
| `assets/city.glb` | процедурную застройку (небо, земля и Темза остаются) |

Как получить файлы: открыть страницу модели на Sketchfab → **Download 3D Model** →
формат **glTF (.glb)** (нужен аккаунт; скачивание доступно, если автор его разрешил),
переименовать и положить в `assets/`. Игра сама масштабирует модель:
байк — в габарит ~4 м, город — в квадрат ~1900 м, основание кладётся на нулевой уровень.

Для `city.glb` коллизии строятся как AABB по мешам модели: меши шире 420 м
считаются подложкой/рельефом и в коллайдеры не попадают. Если модель — один слитый меш,
столкновения со зданиями работать не будут, останется только «пол».

Модели, вдохновившие проект:
[GIRL WARRIOR MOTORCYCLE CYBER](https://sketchfab.com/3d-models/girl-warrior-motorcycle-cyber-by-oscar-creativo-c27030b41da04de29b0ba78c486a9b31)
by OSCAR CREATIVO и
[London Financial District](https://sketchfab.com/3d-models/london-financial-district-74cc9216f2c24efa96fe2554897e5966)
by 333DDD. Файлы моделей в репозиторий не входят — скачивайте их сами и соблюдайте лицензию авторов.

## Что внутри

```
game/
├── index.html        экраны, HUD, importmap
├── style.css         киберпанк-интерфейс
├── src/
│   ├── main.js       рендерер, пост-обработка, состояния, главный цикл
│   ├── city.js       генерация Сити, Темза, ориентиры, трафик, небо, слот city.glb
│   ├── rider.js      байк + райдер, неоновые следы, слот bike.glb
│   ├── player.js     полётная модель и камера за спиной
│   ├── gameplay.js   трасса из колец, таймер, комбо, рекорд
│   ├── hud.js        приборы и миникарта
│   ├── audio.js      синтез турбины, ветра и сигналов (WebAudio, без файлов)
│   └── input.js      клавиатура, мышь с pointer lock, геймпад, тач
└── vendor/three/     three.js r169 (core + нужные аддоны)
```

Ориентиры Сити собраны процедурно и узнаваемы по силуэту: 30 St Mary Axe («Огурец»),
122 Leadenhall («Тёрка»), 20 Fenchurch («Уоки-Токи»), 22 Bishopsgate, Tower 42,
Lloyd's, The Shard, собор Святого Павла и Tower Bridge — сквозь его пролёт проходит
одно из колец трассы.

Технически: вся рядовая застройка слита в один меш (`mergeGeometries`) с процедурной
текстурой фасадов и эмиссивной картой окон; трафик — `InstancedMesh`; отражения в стекле —
PMREM-карта, снятая с того же шейдерного неба; свечение — `UnrealBloomPass`.
Столкновения — AABB-проверка по списку коллайдеров, камера тем же тестом не проваливается в стены.

## Настройки

В паузе: bloom, инверсия оси Y, звук, чувствительность мыши и **качество**
(`низкое` снижает pixel ratio и выключает bloom — для слабых GPU и ноутбуков).
Лучшее время хранится в `localStorage`.
